# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone.

Be respectful, discuss ideas rather than people, assume good intent while accepting correction, and avoid discriminatory, threatening, sexual, or personally identifying content. Do not publish another person's secrets, private paths, or private communications.

Project maintainers may edit or remove contributions and participation that violate these expectations. Report conduct issues privately to the repository owner; add a dedicated contact before the public launch.
